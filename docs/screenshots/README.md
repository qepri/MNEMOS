# Screenshots

Drop real UI screenshots here, then uncomment the `<img>` block in the root `README.md`
("See it in action" section). Real screenshots convert visitors far better than any
feature list, so this is the single highest-leverage thing you can add.

Suggested three (named exactly so the README picks them up):

| File | What to capture |
|---|---|
| `search.png` | The **Search** page with a query and matching passages listed |
| `chat.png` | **Chat** answering a question with source citations visible |
| `graph.png` | The **Graph** view — the concept hypergraph in Cytoscape |

Tips:
- Use a clean library with a few real documents (not empty states).
- ~1200–1600px wide, PNG. Crop to the app, hide any personal data.
- Optional extras: `wiki.png` (a concept article), `upload.png` (drag-and-drop upload).
